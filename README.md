
# Roblox Spillprosjekt

Dette prosjektet inneholder dokumentasjon av to spill
som jeg har utviklet i Roblox Studio.

## Spill 1 – 2D Basketball

Et basketballspill der spillerne konkurrerer om å score
poeng ved å få basketballen i kurven.

## Spill 2 – Please Donate

Et sosialt spill der spillerne kan donere fake Robux
til hverandre. Det brukes ikke ekte Robux.

## Verktøy
- Roblox Studio
- Visual Studio Code
- GitHub
- KI som hjelpemiddel

## Hvordan spille

Spillene åpnes gjennom Roblox-lenkene nedenfor.
